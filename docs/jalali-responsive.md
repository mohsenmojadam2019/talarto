# به‌روزرسانی جلالی و فرم‌های واکنش‌گرا — ۱۴۰۵/۰۷

تالار رویای ماندگار یک وب‌سایت **تک‌مجموعه‌ای** است. SaaS و مارکت‌پلیس نیست.

## تاریخ‌ها

- کل تاریخ‌های نمایشی کاربر در پیش‌فاکتور چاپی، تاریخ پرداخت‌ها، تقویم و پنل‌ها با تقویم جلالی نمایش داده می‌شوند.
- قوانین قیمت‌گذاری در پنل مدیریت فیلدهای `start_date_jalali` و `end_date_jalali` دارند. کاربر تاریخ شمسی را انتخاب می‌کند؛ سمت سرور به تاریخ داخلی دیتابیس تبدیل می‌شود.
- بازه معکوس یا تاریخ نامعتبر رد می‌شود. برای قوانین بدون محدودیت تاریخ می‌توان هر دو فیلد را خالی گذاشت.
- انتخابگر تقویم برای مدیریت امکان مراجعه به ماه‌های گذشته و آینده را دارد. تاریخ‌های قدیمی برای فرم رزرو مشتری غیرقابل انتخاب باقی می‌مانند.
- نمودار ماهانه و جمع درآمد ماه جاری بر اساس مرز **ماه‌های جلالی** محاسبه می‌شوند.
- خروجی CSV ادمین نیز تاریخ جلالی دارد. تاریخ‌های فنی دیتابیس، timestamps داخلی، و فیلد استاندارد Sitemap همچنان در قالب Gregorian/ISO باقی می‌مانند؛ نمایش کاربر جلالی است.

## طراحی فرم‌ها و قابلیت‌ها

- `public/assets/css/form-system.css`: طراحی مشترک فرم‌های عمومی، رزرو، مشتری، مدیریت، مالی و مدیا.
- `public/assets/js/form-enhancements.js`: نمایش/مخفی‌کردن رمز عبور، اعتبارسنجی مرورگر، جلوگیری از کلیک دوباره روی ارسال، نرمال‌سازی ارقام ورودی، نشانگر طول متن، مراحل رزرو و جستجو در فهرست‌های فعلاً بارگذاری‌شده.
- جستجوی رزرو در پنل کاربر و بخش گزارش مالی صرفاً در ردیف‌های فعلی صفحه است؛ برای جستجوی کامل دیتابیس به فیلتر سرور نیاز است.
- خروجی حداکثر ۵۰۰۰ رزرو اخیر، با مجوز مدیر از `/admin/commerce/reservations/export` در قالب CSV UTF-8. داده‌های متن برای جلوگیری از اجرای فرمول Spreadsheet پاک‌سازی می‌شوند.
- فیلدهای فرم‌ها و جداول در عرض‌های ۳۹۰، ۷۶۸ و ۱۴۴۰ پیکسل بررسی شدند.

## آزمون محلی

```bash
cd ~/Videos/talarto
docker compose up -d --build
docker run --rm --network none --entrypoint php -v "$PWD:/app" -w /app talarto-app:latest vendor/bin/phpunit --colors=never
python3 local-backups/qa_responsive_jalali.py
```

اسکریپت مرورگر محلی در Git منتشر نمی‌شود زیرا برای تست به نشست مدیریتی محلی نیاز دارد. رمز عبور در سورس یا خروجی Git ثبت نشده است.

این تست‌های QA رندر و دسترسی را می‌سنجند؛ به‌معنای تضمین طراحی پیکسلی تمامی حالت‌های مرورگر یا آمادگی پرداخت عمومی نیست.
