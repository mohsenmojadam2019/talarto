# مدیا لایبرری تالار رویای ماندگار

این پروژه **تک‌تالاری** است و SaaS یا مارکت‌پلیس ندارد.

## ورود تصاویر مراسم

1. در سیستم god وارد http://127.0.0.1:8000/admin شوید.
2. در سایدبار بخش **مدیا لایبرری** را باز کنید.
3. برای تصاویر مستقل: تا ۱۲ عکس PNG/JPG/WebP (هر کدام حداکثر ۸ مگابایت) آپلود کنید.
4. برای بسته تأییدشده مراسم، فایل `talarto_iranian_venue_media_10.zip` را از گفتگو دانلود و از قسمت **ورود بسته ZIP** بارگذاری کنید.
5. گزینه **جایگزین‌کردن تصاویر نمونه فعلی و تغییر بنر** را فعال بگذارید؛ عکس‌های نمونه قبلی غیرفعال می‌شوند و تصویر اول بسته روی بنر قرار می‌گیرد.
6. می‌توانید عنوان، دسته‌بندی، متن جایگزین و ترتیب هر عکس را جداگانه تغییر دهید.

## دسته‌بندی‌ها

سالن عروسی، تولد، عقد، نامزدی، پذیرایی و غذا، دکوراسیون، محوطه.

ZIP دارای manifest.json است و دسته‌بندی مختص هر فایل را خودکار وارد می‌کند. ZIP فقط فایل تصویری معتبر وارد می‌کند و مسیرهای دلخواه داخل آرشیو را اجرا یا استخراج نمی‌کند.

## مسیرها

- `POST /admin/media` آپلود چندگانه
- `POST /admin/media/import` ورود ZIP
- `PATCH /admin/media/{mediaAsset}` ویرایش
- `POST /admin/media/{mediaAsset}/hero` تصویر Hero
- `POST /admin/media/{mediaAsset}/about` تصویر معرفی
- `DELETE /admin/media/{mediaAsset}` حذف

همه عملیات زیر middleware اختصاصی مدیر قرار دارند. تصاویر آپلودشده در Volume پایدار storage نگه‌داری می‌شوند. عکس‌های نمایشی تولید هوش مصنوعی هستند و نباید به‌جای عکس‌های مستند یک تالار واقعی معرفی شوند.

## کنترل کیفیت

```bash
cd ~/Videos/talarto
docker compose up -d --build
docker run --rm --network none --entrypoint php -v "$PWD:/app" -w /app talarto-app:latest vendor/bin/phpunit
```
