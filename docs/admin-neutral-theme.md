# تم سفید و خاکستری پنل مدیریت

پنل ادمین تالارتو در `/admin` و `/admin/commerce` از یک طراحی سفید/خاکستری مشترک استفاده می‌کند. صفحه ورود ادمین نیز در `/admin/login` هماهنگ است.

- رنگ سطح: `#f3f4f6` (خاکستری بسیار روشن)
- رنگ کارت، فرم و سایدبار: `#ffffff`
- متن اصلی: `#20252e`
- خطوط جداکننده: `#e5e8ed`
- انتخاب منو: `#eceef1`
- دکمه اصلی: `#343d49` (ذغالی)
- جدول‌ها، گراف‌ها، شاخص‌ها، تقویم، فرم‌های مالی و مدیا لایبرری نیز همین طیف را دارند.
- تصویر تزئینی پشت منوی ادمین حذف شده است؛ نشان برند با کاهش اشباع باقی مانده است.

CSS اصلی: `public/assets/css/admin-neutral.css`

این استایل صرفاً روی مسیرهای مدیریت بارگذاری می‌شود؛ رنگ‌های سایت عمومی دست‌نخورده‌اند. تمام محتوا و شاخص‌ها همچنان از دیتابیس می‌آیند.

تست مرورگر روی عرض‌های ۳۹۰، ۷۶۸، ۱۴۴۰ و ۱۹۲۰ انجام شد. برای هر عرض رنگ پس‌زمینه، رنگ سایدبار، چسبیدن سایدبار به لبه راست، عدم اسکرول افقی و نبود خطای JavaScript بررسی شد.
