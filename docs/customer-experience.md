# بازطراحی ورود و پنل مشتری تالارتو

این پروژه مربوط به **یک تالار** است؛ SaaS و مارکت‌پلیس نیست.

## صفحه ورود و ثبت‌نام

- `resources/views/auth/login.blade.php` و `register.blade.php`
- کارت روشن روی عکس سالن، پالت کرم/طلایی، کنتراست خوانا، لیبل‌ها و حالات خطا
- ورود با موبایل و رمز عبور و قابلیت یادآوری حساب؛ همان احراز هویت Laravel قبلی باقی مانده است
- دکمه نمایش/مخفی‌کردن رمز از `form-enhancements.js`
- تصاویر استفاده‌شده در پس‌زمینه از فایل‌های محلی `public/assets/venue/` هستند؛ نیازی به سرویس عکس خارجی نیست

## داشبورد مشتری

- `resources/views/account/dashboard.blade.php` و `account/partials/sidebar.blade.php`
- بنر سالن، ۴ شاخص که از رزروهای واقعی صاحب حساب محاسبه می‌شوند: کل رزروها، آینده، برگزارشده، در انتظار پیگیری
- جدول ۸ رزرو آخر با تاریخ **جلالی**، سانس، تعداد مهمان، مبلغ، وضعیت و کد پیگیری
- تصویر تالار **یکسان** برای رزروها، چون سایت تک‌تالاری است
- لینک واقعی به رزرو جدید، جزئیات رزرو، گالری، تماس و تنظیمات حساب

## تنظیمات حساب

- `GET /account/profile` با دسترسی محدود به مشتری لاگین‌شده
- `PATCH /account/profile`: تغییر نام و ایمیل اختیاری، با اعتبارسنجی
- شماره موبایل فعلاً شناسه ورود است و بدون فرایند تأیید مجدد تغییر نمی‌کند
- `PUT /account/profile/password`: الزام رمز فعلی، تأیید رمز جدید و چرخش remember token
- هیچ پسوردی در GitHub ذخیره نشده است

## طراحی و تست

- `public/assets/css/customer-experience.css` با Breakpointهای 800، 560 و 1100 پیکسل
- کارت خلاصه و جدول دارای اسکرول داخلی افقی، بدون اسکرول افقی کل سند
- پنل خلاصه هزینه رزرو نیز روشن شد و از مشکی سنگین به کرم/طلایی تغییر کرد
- `tests/Feature/CustomerExperienceTest.php` پوشش احراز هویت، محرمانگی رزروها و امنیت تغییر رمز را فراهم می‌کند
- مرورگر Chrome در عرض‌های 390، 768 و 1440 برای ورود، ثبت‌نام، پنل و پروفایل کنترل شد؛ محیط تست از دیتابیس اصلی جدا است

## اجرای محلی

```bash
cd ~/Videos/talarto
docker compose up -d --build
docker compose ps
docker run --rm --network none --entrypoint php -v "$PWD:/app" -w /app talarto-app:latest vendor/bin/phpunit --colors=never
```

سایت: `http://127.0.0.1:8000` | ورود: `/login` | پنل: `/account` | تنظیمات: `/account/profile`

**نکته:** اعداد و مشتریان داخل تصویر رفرنس، محتوای نمونه طراحی بودند. این نسخه داده‌های واقعی حساب را نشان می‌دهد؛ وعده علاقه‌مندی چندتالاره یا رزرو تالارهای مختلف در آن پیاده نشده است.
